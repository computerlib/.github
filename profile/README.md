## うちの会社のシステム部

考えるところから、使い続けるところまで、まとめて支えます。

社内にIT部門を置くほどではない。でも、相談できる相手はほしい。そんな会社の「システム部」を、まるごと外から引き受けます。

- **考える** … 何から手をつけるか、一緒に決める
- **作る** … ホームページ・ネットショップ・社内システムを形にする
- **活かす** … 生成AIやデータを、日々の仕事に効かせる
- **続ける** … 公開したあとも、止めない・直す・育てる
